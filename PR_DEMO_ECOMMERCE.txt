## 🎨 Test Features

### Flexible Selectors
Multiple fallback strategies for different site structures:
```python
product_selectors = [
    ("css", ".product-grid"),
    ("css", ".product-list"),
    ("css", "[class*='product']"),
    ("xpath", "//div[contains(@class, 'product')]")
]
```

### Graceful Degradation
Tests print informative messages instead of failing when optional elements aren't found:
```python
if not filters_found:
    print("Note: Filters not found - may not be available on this site")
```

### Responsive Testing
Tests verify functionality across 3 viewport sizes:
- 1920x1080 (Desktop)
- 768x1024 (Tablet)
- 375x667 (Mobile)

### Site-Agnostic Design
Tests work with various e-commerce platforms by using flexible selectors and handling missing elements gracefully.

## 🧪 Testing Instructions

### Run All Tests
```bash
pytest tests/demo_ecommerce/ -v
```

### Run Smoke Tests (7 tests)
```bash
pytest tests/demo_ecommerce/ -m smoke -v
```

### Run Regression Tests (5 tests)
```bash
pytest tests/demo_ecommerce/ -m regression -v
```

### Run Specific Test File
```bash
pytest tests/demo_ecommerce/test_product_catalog.py -v
pytest tests/demo_ecommerce/test_shopping_cart.py -v
pytest tests/demo_ecommerce/test_user_account.py -v
```

### With Allure Reports
```bash
pytest tests/demo_ecommerce/ --alluredir=reports/allure-results
allure serve reports/allure-results
```

### In Docker
```bash
docker run --rm test-automation:latest \
  pytest tests/demo_ecommerce/ -v --alluredir=reports/allure-results
```
